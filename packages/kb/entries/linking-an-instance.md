tags: [link, connect, instance, server, token, register, licence]
---
1. In the Portal, open **Instances → Add instance** and copy the token. It is valid for
   {{registration.tokenValidity}} and works once.
2. In Qubo, open **Settings → Organization → Qubo Portal**, paste the token and save.
3. The server appears under Instances within a minute and receives your plan.

Unlinking returns the server to {{plans.free.name}} limits; nothing is deleted.
